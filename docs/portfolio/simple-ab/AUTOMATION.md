# A/B 운영 품질 자동점검

방문 통계나 실험 관리는 하지 않는다. 자동화 대상은 기존 두 화면의 기술적 품질과
원본 보존이다. 외부 분석 서비스·새 호스팅·계정 연결은 추가하지 않는다.

## 운영 정책

- 주간 점검: 월요일 오전 10시, Asia/Seoul.
- Mac과 기존 Hermes gateway가 실행 중일 때 로컬에서 수행한다.
- 격리된 임시 복사본에서 빌드·A/B 배정/저장·no-JS·링크·이미지/PDF·모바일·접근성을 검사한다.
- 작업 중인 체크아웃이 dirty이거나 점검 도중 바뀌면 대기/보고한다. 사용자 파일을 되돌리지 않는다.
- 정상 상태가 같으면 모델을 다시 부르지 않는다. 상세 보고서는 비공개 로컬에 보관한다.
- 문제가 달라지면 에이전트가 원인을 구분한다. 재현되는 코드 결함에 한해 최소 수정안을
  검증하고 초안 PR로 제안한다. 이미 검토 중인 동일 문제의 PR은 중복 생성하지 않는다.
- 네트워크·인증·도구·계정 배포 차단은 보고만 한다. 결제/권한/호스팅 우회 변경은 하지 않는다.
- 병합·배포·기본 홈 교체·방문자 비중 조정은 자동화하지 않는다.

## 실행과 증거

실행기는 `tools/portfolio_maintenance.py`, 단위 검증은
`tools/test_portfolio_maintenance.py`다. 예약 작업은 이 실행기의 검증된 사본과
설정·QA 자산을 사용자 프로필의 비공개 자동화 디렉터리에 설치해 사용한다.
주간 실행에 필요한 axe 파일은 24시간 scratch 캐시 밖에 보관하고 원래 라이선스
고지와 파일 hash를 보존한다. QA의 결과 경로는 환경 변수로 격리한다.

일정 등록, 스케줄러의 실제 가동, 최초 실행의 성공, 결과 전달은 별도로 확인한다.
예약 등록만으로 작동 완료라고 보지 않는다. TUI 전달은 대화 기록의 알림이며
휴대폰 푸시를 뜻하지 않는다. 실제 설치/실행 영수증은 비공개 프로필에 보관한다.

현재 A/B 소스는 초안 PR #3의 기능 브랜치다. PR이 병합/종료되거나 대상 체크아웃이
제거되면 대상을 갱신하기 전까지 자동 수정하지 않는다. 원본 공개 홈의 HTTP 성공은
새 `/ab/` 경로의 배포 증거가 아니다. 공개 배포 차단은 이 자동점검과 별도로 남는다.
