# Two first-screen studies, not another full portfolio

## Design correction
The plain C direction did not answer the owner's aesthetic objection. Authentic
copy and fewer decorations are not an art direction. Scope is now two contrasting
first screens, leaving A/B/C and all approved facts untouched. No publication,
analytics or automatic winner selection. Verbatim feedback remains private.

Audience: people evaluating Kangnam Kim's applied AI engineering work. Primary
job: remember a person and immediately understand the role, with direct routes to
real work and résumé. No new career facts, invented hobbies or designer claims.

coral #ee5c38. One memorable gesture: massive Korean name in Black Han Sans.
Body remains quiet. Bricolage Grotesque is used for Latin name/role. Local font
subsets and OFL notices, no runtime Google calls. No serif/cream defaults.

Left-aligned text; optical name spacing; a firm baseline, not random rotation.
Actual work is smaller evidence, not four matching project cards. No oversized
marketing slogan. The owner's actual name anchors the visual treatment.

Palette: cobalt #253fc4, chalk #f4f6ff, lavender #bab6ef, melon #ff9c72,
mint #a9dfd0. The blue field and one carefully lit composition do the work.
Name/role are quieter than type study. Three spatial blocks refer specifically
to the existing Unreal actor-spawn work. They are original web artwork, explicitly

No autoplay, cursor-following or scroll hijacking. Layout change is user-triggered

## Pre-build critique
Reject the first obvious ideas: no warm-clay editorial redesign, near-black/acid
tech gallery, generic hero slogan, repeating eyebrow/mono labels or three numbered
cards. A novelty font alone is insufficient: type study must coordinate scale,
background, spacing and one subordinate real artifact; object study must make a
single spatial element dominant rather than surround it with UI gadgets.
These are aesthetic hypotheses, not assertions that either is tasteful or approved.

## Guardrails
First-screen-only Korean studies, self-contained and noindex. Preserve every
tracked baseline file and every rendered A/B/C route. No package/lockfile changes,
private disclosures, student images, existing server replacement or GitHub retry.
Inspect desktop and mobile actual pixels, font load and reduced motion before
presenting. Do not center the owner report on engineering pass counts.
